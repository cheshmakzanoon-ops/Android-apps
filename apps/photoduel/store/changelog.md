# Changelog

## 0.1.0-mvp (development build, not released)

- Guest identity, session persistence and recovery codes (backend and Android client).
- Private rooms, invitations with expiry and revocation, and room membership rules.
- Challenge lifecycle with server-side deadlines, submissions, immutable ballots and deterministic results.
- Reporting, blocking, auto-hide on three reports, account and room deletion.
- Moderation command-line tool with an audit log.
- Thirty curated prompts.

**Known limitations:** no live backend; no web deletion page; no App Links; no push notifications; no physical-device testing; Android build verified only by GitHub Actions when that run is green.
